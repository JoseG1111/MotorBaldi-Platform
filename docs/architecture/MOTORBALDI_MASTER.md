# MotorBaldi Platform Master Architecture

MotorBaldi Platform is a modular monolith deployed primarily on Cloudflare.

Foundation runtime:

- API Worker on Cloudflare Workers.
- Background Worker with Queue and scheduled handlers.
- Cloudflare D1 as canonical SQL persistence.
- Cloudflare R2 for private files, documents and images.
- Cloudflare Queues as async transport.
- Durable Objects only for strong coordination such as idempotency and outbox relay ownership.
- Workers Rate Limiting for abuse protection.
- Turnstile adapter for future public/auth abuse protection.
- Worker secrets for remote secrets.
- Workers logs/traces plus structured application events for observability.

The repository does not contain the public marketing website. Website integration is documented as a future API client contract.

Data rules:

- UUIDv7 generated by application where identifiers are needed.
- Human identifiers such as email, phone, plate or VIN are never primary keys.
- Time is stored as UTC ISO 8601 `TEXT` in D1.
- Money is integer minor units plus 3 letter currency code; never float.
- D1/SQLite constraints are used for PK, FK, UNIQUE, CHECK, NOT NULL and indexes.
- D1 environment metadata must match Worker environment or the runtime fails closed.

Boundaries:

- Apps can depend on public packages.
- Packages do not depend on apps.
- Internal workspace dependencies use `workspace:*`.
- Business/domain code stays behind infrastructure interfaces and does not receive Cloudflare bindings directly unless it is infrastructure code.
