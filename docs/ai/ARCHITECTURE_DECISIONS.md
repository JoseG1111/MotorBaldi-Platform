# Accepted architecture and guardrails

This is an index of decisions, not a replacement for [master architecture](../architecture/MOTORBALDI_MASTER.md), [Phase 1 design](../architecture/phase-1-identity-crm-organizations.md), [ADRs](../adr/), [Cloudflare runbooks](../cloudflare/), or [website contract](../contracts/WEBSITE_INTEGRATION.md). If a summary conflicts with code or a current accepted ADR, inspect and reconcile before proceeding. ADR 0011's CF-0 description of no business account was superseded in implementation by Phase 1; ADR 0022's manual-only remote setup describes CF-0, not today's Development state.

- Platform is separate from the public marketing repository ([ADR 0021](../adr/0021-repository-split.md)). MotorBaldi owns business identity and CRM; HubSpot is not Core. The workspace is a modular monolith with API, background Worker, Portal, and Admin ([ADR 0013](../adr/0013-workspace-boundaries.md)).
- Workers run compute, D1 owns transactional/business SQL, R2 holds private objects, Queues transport asynchronous work, and Durable Objects coordinate only where serialization is required. KV has no current correctness role. Keep R2 private. See [ADRs 0014–0020](../adr/), especially [outbox delivery](../adr/0018-cloudflare-queues.md) and [coordination debt](../adr/0019-durable-object-coordination.md).
- People and accounts differ; organizations never log in. Authorization supports multiple roles, organizations, and locations, with default-deny RBAC plus context. Better Auth owns technical login; privileged actions require verified MFA and a session created after enrollment. Remote public signup remains restricted by current config. See [Phase 1 design](../architecture/phase-1-identity-crm-organizations.md).
- Worker secrets hold secrets. Public anonymous writes require Turnstile and rate limiting. Logs must not expose credentials, tokens, secrets, or PII. Audit/security records retain designed append-only semantics. Events use transactional outbox, at-least-once delivery, and idempotent consumers.
- Use UUIDv7, UTC ISO timestamps, integer minor-unit money plus currency, and optimistic concurrency where established. Mutable email, VIN, plate, and similar business identifiers are never primary keys. Data classes are PUBLIC, INTERNAL, CONFIDENTIAL, and RESTRICTED. UI is Spanish-first and localization-ready; target WCAG 2.2 AA.
- Top-level Wrangler config is local; named development/staging/production are remote ([ADR 0020](../adr/0020-cloudflare-environments.md)). Select the environment explicitly for remote commands. Production deployment requires explicit human authorization. The final canonical app hostname is `app.motorbaldi.com`; Development currently uses `workers.dev`. Development and Production Turnstile widgets and secrets stay separate.
- Vehicle Core decisions: central vehicle, generic kind/spec, historical identifiers, garage distinct from legal ownership, no private plate lookup, explicit owner/driver/workshop relationships and access grants, append-oriented odometer, immutable final professional records amended rather than edited. Partner is a capability/relationship, not an exclusive organization type. Trace exact details to current domain docs when implementing.

- The operator delegated implementation choices on 2026-10-09. Vehicle Core starts with staff-reviewed issuance and claims, explicit exact grants, and verified-organization professional authorship; see the [bounded Phase 2 policy](../architecture/phase-2-vehicle-core.md#initial-issuance-and-review-policy). This resolves the prior vehicle-policy blocker without relaxing the global security or production boundaries.

- Workshop Operations starts with the explicitly delegated bounded [operational contract](../architecture/phase-3-workshop-operations.md): organization/location authorization plus exact vehicle grants, assigned execution, immutable professional completion evidence and MFA closure. This does not establish commercial/legal approval, payment or warranty rules.

- [ADR 0024](../adr/0024-owner-antimalware-deferral.md) records the owner-approved real scanner deferral ($0 additional-service budget). Preserve the existing scanner port/private lifecycle and fail-closed downloads; trusted Development files remain quarantined. Revisit real scanning before public upload/download enablement. Independent milestones depend on their verified prerequisites, not a pretend scanner verification.

- The bounded [Inspection contract](../architecture/phase-4-inspections.md) reuses canonical professional records and amendments; generic observations do not establish legal verdicts, prices or mandatory checklists. Evidence remains private and ACTIVE-only; ADR 0024 deferral continues to apply.

- [ADR 0019](../adr/0019-durable-object-coordination.md) now requires prepared generic D1 commands to atomically commit replay claim/receipt/business/audit/outbox. MB-P5-000 verifies the generic crash-window fix independently of the earlier lead-specific fix. External financial effects still require deterministic provider identifiers and unknown-outcome reconciliation; generic replay TTL is not lifetime financial deduplication.

- [ADR 0025](../adr/0025-membership-billing-commercial-boundaries.md) accepts the owner-defined account subscription and separate configurable partner commission model. Free access remains; price/period/vehicle-limit/entitlement foundations are in [Phase 5](../architecture/phase-5-membership-billing.md). Production commercial approvals stay distinct from safe Development progress.

- Communications extend existing Messaging ports with explicit acceptance/unknown/unavailable outcomes, current authority and provider-side idempotency/reconciliation prerequisites. Human guidance defaults disabled with configurable finite hours/usage; no paid or fictitious provider/diagnosis. See [Phase 6 contract](../architecture/phase-6-communications-support.md).

- The owner approved the [general-support policy](../architecture/phase-6-communications-support.md#approved-support-workflow--2026-10-10) on 2026-10-10: ACTIVE customers own create/read/reply/close; exact platform SUPPORT_AGENT/PLATFORM_SUPERADMIN plus assured MFA handle staff actions; organization roles confer no support access. OPEN/ASSIGNED/CLOSED is terminal, with immutable history and preserved closing metadata. Premium assistance remains disabled pending explicit operating/readiness/entitlement/usage rules.
